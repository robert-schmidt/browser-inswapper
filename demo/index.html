heisenbert-faceswap

Real-time face swap that runs entirely in your browser. Nothing is uploaded. Built for heisenbert.com.

On a Mac? Turn on Chrome's neural network support for about 3× faster swaps. It lets the browser run the model through Core ML (on an M2 Max: 30 ms per swap instead of 95 ms).
  1. Copy chrome://flags/#web-machine-learning-neural-network and open it in a new tab (Edge: edge://flags, same name).
  2. Set Enables WebNN API to Enabled, then click Relaunch.
  3. Come back and keep Fastest for this device: it tries both and keeps the faster one.
